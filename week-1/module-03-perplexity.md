## Learning Objectives

- Set up Perplexity AI for research and daily use

---

## What is Perplexity AI?

Perplexity AI is an **AI-powered answer engine** that combines the power of large language models with real-time web search. Unlike traditional search engines, Perplexity:

- **Provides direct answers** with cited sources (not just links)
- **Computer Use:** Can browse the web, interact with websites, and execute multi-step tasks on your behalf
- **Finance Mode:** Tracks stocks, analyzes financial data, and generates investment insights
- **Follows up** intelligently with context from previous queries

## Step-by-Step Activities

### Activity 1: Account Setup and Configuration

1. Go to [perplexity.ai](https://www.perplexity.ai) and create an account
2. Upgrade to **Pro** for access to advanced features (Computer, Finance, file uploads)
3. Install the Perplexity mobile app (iOS/Android) for on-the-go research
4. Install the **Perplexity browser extension** for quick access from any webpage
5. Explore the settings:
   - Set preferred AI model (default vs. advanced)
   - Enable/disable sources you trust
   - Configure output language preferences

### Activity 2: Explore Computer Use

Perplexity's Computer feature allows the AI to browse, interact, and execute tasks on the web for you.

**Try these tasks:**

1. **Web Research Task:**
   ```
   Use Computer to find the top 5 Y Combinator startups from the latest batch
   working on AI agents. For each, get their website, funding amount, and
   one-sentence description.
   ```

2. **Data Collection Task:**
   ```
   Use Computer to go to GitHub Trending and collect the top 10 trending
   repositories this week. List each with: name, stars, language, and description.
   ```

3. **Comparison Task:**
   ```
   Use Computer to compare pricing plans of Notion, Obsidian, and Coda.
   Create a comparison table with features, pricing tiers, and AI capabilities.
   ```

**Key Tips for Computer Use:**
- Be specific about what you want collected
- Specify the output format (table, list, report)
- Review results since web interactions can sometimes miss dynamic content

### Activity 3: Set Up Finance Mode

Perplexity Finance gives you AI-powered financial analysis and market insights.

**Setup Steps:**
1. Navigate to Finance section in Perplexity
2. Set up your watchlist with stocks/assets you want to track
3. Configure alerts for price movements or news

**Try these financial queries:**

1. **Stock Analysis:**
   ```
   Analyze NVIDIA (NVDA) stock performance over the last 6 months.
   Include key metrics, recent earnings, and analyst consensus.
   ```

2. **Market Research:**
   ```
   Compare the AI sector ETFs (BOTZ, ROBO, AIQ). Which has performed
   best in 2026? Show a comparison with expense ratios and top holdings.
   ```

3. **Financial Summary:**
   ```
   Summarize the latest Federal Reserve meeting minutes and explain
   the potential impact on tech stocks in simple terms.
   ```

4. **Investment Research:**
   ```
   I have $5,000 to invest in AI-related stocks. Suggest a diversified
   portfolio with reasoning. Include risk assessment for each pick.
   ```

### Activity 4: Advanced Research Workflows

**Build a complete research pipeline using Perplexity:**

1. **Step 1 - Broad Research:**
   ```
   What are the top trends in AI automation for 2026?
   ```

2. **Step 2 - Deep Dive:**
   ```
   Based on the trends above, give me a detailed analysis of
   the "AI agents" trend. Include key players, market size,
   and growth projections.
   ```

3. **Step 3 - Competitive Analysis:**
   ```
   Compare the top 5 AI agent platforms (Manus, CrewAI, AutoGen,
   LangGraph, OpenClaw). Create a feature comparison matrix.
   ```

4. **Step 4 - Synthesize:**
   ```
   Based on all our research above, write a 500-word executive
   summary suitable for a startup pitch deck about opportunities
   in the AI agent space.
   ```

## Perplexity Pro Tips

| Tip | Description |
|-----|-------------|
| **Use Collections** | Save related searches into Collections for organized research |
| **Upload Files** | Upload PDFs, CSVs, or images for AI analysis |
| **Focus Modes** | Switch between Writing, Academic, Math, etc. for specialized output |
| **Thread Context** | Perplexity remembers your conversation - build on previous queries |
| **Share Results** | Generate shareable links for your research threads |
| **Citation Checking** | Always verify critical claims by clicking through to source links |

## Perplexity vs. Traditional Search

| Feature | Google Search | Perplexity AI |
|---------|--------------|---------------|
| Output | Links to websites | Direct answers with citations |
| Follow-up | New search each time | Contextual conversation |
| File Analysis | Not available | Upload and analyze documents |
| Computer Use | Not available | AI browses and acts for you |
| Finance | Google Finance (basic) | AI-powered analysis and insights |
| Research Depth | Manual synthesis | Automated multi-source synthesis |

## 📊 Assessment

The program culminates in a **Capstone Weekend Build** where students:

1. **Ideate** a micro-startup or personal project using AI
2. **Build** a working MVP using Claude Code
3. **Automate** at least one workflow with n8n or Zapier
4. **Document** everything in their Notion Second Brain
5. **Present** a 5-minute demo to the cohort

| Criteria | Weight |
|----------|--------|
| Tool proficiency demonstrated | 25% |
| Creativity of solution | 20% |
| Automation integration | 20% |
| Documentation quality | 15% |
| Presentation & communication | 20% |
